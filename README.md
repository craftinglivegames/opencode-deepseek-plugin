# opencode-deepseek-plugin

Плагин [OpenCode](https://opencode.ai), который позволяет агенту генерировать тексты через
**веб-чат DeepSeek** (chat.deepseek.com) — рефераты, курсовые, главы, введения, списки
литературы — и перегенерировать их по запросу. Работает как обычный пользовательский чат:
**без API-ключей**, через фоновый браузер (Chromium/Edge), с «живым» темпом ввода, чтобы
аккаунт не заблокировали за подозрительную активность.

Вход в аккаунт DeepSeek выполняется автоматически по логину и паролю, но **пароль нигде не
хранится**: агент получает его от вас только в тот момент, когда вход действительно нужен,
после чего сессия живёт в профиле браузера до истечения её срока.

## Что умеет

| Инструмент | Что делает |
|---|---|
| `deepseek_status` | Состояние моста: запущен ли, выполнен ли вход. Сам поднимает мост при необходимости |
| `deepseek_ask` | Отправляет запрос в чат DeepSeek и возвращает готовый текст (новый чат или продолжение диалога, 🧠 размышление, 🌐 поиск, картинки-вложения) |
| `deepseek_rewrite` | Перегенерировать готовый фрагмент по инструкции (иначе/короче/дороже/проще) — в том же диалоге, поэтому сохраняется контекст |
| `deepseek_login` | Вход в аккаунт: с логином/паролем, `confirm=true` (проверить вход) или без аргументов — открыть видимое окно браузера для ручного входа |

Примеры запросов агенту:

- «Сделай мне главу 2 курсовой по менеджменту на тему „Цифровая трансформация“, ~15 страниц, ГОСТ»;
- «Перепиши этот абзац проще и без канцелярита» (плюс фрагмент текста);
- «Составь план реферата из 5 глав и раскрой введение»;
- «Сократи вдвое и добавь ссылки на источники».

## Как это работает

```
OpenCode (агент)
   │  инструменты deepseek_*  (index.ts)
   ▼
Локальный HTTP-мост  http://127.0.0.1:8777   (Python + FastAPI + Playwright)
   │  headless-браузер со своим профилем, «живой» ввод запросов
   ▼
chat.deepseek.com  (ваша учётная запись, веб-чат)
```

Мост — это адаптированная версия моста из надстройки Word ([Plugin Word](../)),
поэтому он проверен в бою: ожидание завершения генерации по стабильности текста,
паузы 3–6,5 с между отправками, печать начала запроса с человеческим темпом и
«вставка» остатка, как из буфера.

## Установка

Нужны Windows, Python 3.10+ и OpenCode V2.

1. Скачайте/скопируйте эту папку (или склонируйте репозиторий).
2. Установите зависимости моста — запустите **`install.ps1`** (правый клик →
   «Запуск с помощью PowerShell»).
3. Добавьте плагин в свой конфиг OpenCode — `~/.config/opencode/opencode.json`
   (глобально) или `opencode.json` проекта:

   ```jsonc
   {
     "$schema": "https://opencode.ai/config.json",
     "plugins": [
       "C:/Полный/Путь/К/opencode-deepseek-plugin"
     ]
   }
   ```

4. Перезапустите OpenCode (`opencode service restart` или просто перезапустите редактор).

Готово. При первом запросе к `deepseek_ask` агент сам поднимет мост; если вход в DeepSeek
не выполнен, он **остановится и попросит у вас логин и пароль**, затем вызовет
`deepseek_login` и продолжит работу. Пароль используется один раз — дальше действует
сессия в профиле браузера (`%LOCALAPPDATA%\OpenCodeDeepSeekBridge\profile`).

## Правила, вшитые в плагин

- **Промпт в чат — как сообщение живого человека.** В описаниях инструментов и в
  системной инструкции сессии прямо запрещено писать DeepSeek, что агент — ИИ, ассистент
  или модель, и упоминать OpenCode/плагины. Чат получает обычный запрос пользователя.
- **Стоп при отсутствии входа.** Если инструмент вернул «ТРЕБУЕТСЯ ВХОД В DEEPSEEK»,
  агент обязан немедленно прекратить генерацию, кратко спросить логин/пароль и вызвать
  `deepseek_login`. Ничего «от себя» до входа не выдумывается.
- **Пароль не сохраняется.** В storage плагина и на диске остаётся только профиль
  браузера с куками сессии.
- **«Живой режим» включён по умолчанию** — защита аккаунта от блокировки.
  Выключается файлом `%LOCALAPPDATA%\OpenCodeDeepSeekBridge\settings.json`:
  `{ "humanMode": false }` (полезно для отладки; влияет на скорость, не на качество).

## Устранение неполадок

- **Мост не стартует** — запустите `install.ps1` вручную и посмотрите `bridge/bridge.log`.
  Порт у плагина свой: **8777** (мост надстройки Word использует 8765, они не мешают друг другу).
- **«ТРЕБУЕТСЯ ВХОД В DEEPSEEK»** — ответьте агенту логином и паролем; либо попросите
  открыть окно для ручного входа (`deepseek_login` без аргументов).
- **403 от CloudFront** — так headless-Chromium ловит защиту DeepSeek; в мосте уже
  подменён User-Agent, обновлять его может понадобиться после выхода новых версий Chromium.
- **Ответ пришёл обрезанным / пустым** — DeepSeek иногда долго «думает»; увеличьте
  `timeout` в запросе или повторите (`thinking` тоже может заметно замедлять ответ).
- **Замедлился чат** — DeepSeek пропускает не больше ~50 сообщений в час. Не гоните
  пачки запросов: делайте паузы, не выключайте живой режим без нужды.

## Важно знать

- Автоматизация веб-чата «хрупкая»: после редизайна интерфейса DeepSeek селекторы в
  `bridge/deepseek_bridge.py` (блок тумблеров, поле ввода, кнопка «Войти») могут
  потребовать правки.
- Используйте аккаунт, к которому у вас есть доступ, и относитесь к генерации
  ответственно: итоговая работа проходит через вашу редактуру, а плагин — лишь
  инструмент получения и обработки текста.
